# CipherVault - SHA256 Encryption Tool

A minimalistic, beautiful web application for SHA256 encryption and hash verification with a modern user interface.

## Features

- **Real-time SHA256 Encryption**: Instantly generate SHA256 hashes as you type
- **Hash Verification**: Verify if a string matches a specific SHA256 hash
- **Dark/Light Theme**: Automatically adapts to your system preferences with manual toggle option
- **Responsive Design**: Works beautifully on all devices
- **Zero Dependencies**: Uses vanilla JavaScript with a single CDN import for SHA256
- **Copy to Clipboard**: One-click copy functionality for easy hash sharing
- **Client-side Processing**: All encryption happens in your browser - no data is sent to servers

## Usage

Simply open `index.html` in your browser to use the application.

### To generate a SHA256 hash:
1. Go to the "Encrypt" tab
2. Enter your text in the input field
3. The SHA256 hash will be generated automatically
4. Click the copy button to copy the hash to clipboard

### To verify a hash:
1. Go to the "Verify" tab
2. Enter the original text
3. Enter the SHA256 hash you want to verify against
4. The application will instantly verify if they match
